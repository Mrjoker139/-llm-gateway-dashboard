拥堵分析 — 什么时段该换模型

按本地小时聚合网关流量，每个模型单独统计。柱子越高 = 那个时段越慢。 拥堵倍数是最慢时段 ÷ 最快时段，超过 2 倍说明有明显时段差异，高峰期可以临时换个模型。
柱子用的是归一化后的 TTFT：先按每个模型的「prompt 长度 → 首字延迟」关系把 各请求折算到同一基准，再取中位数。这样"某个时段正好在处理大文件"不会被误判成拥堵。 鼠标悬停能看到原始值。
修改后立即生效，无需重启

Gemini 节点可用性

Google 对 Antigravity 调用有地区风控，部分出口 IP 会被 User location is not supported 拒掉 —— 同一国家不同 IP 段也可能一个通一个不通。
在下面勾选要用的节点（不勾就不测，避免无谓的节点切换），每个节点会测 3 次（单次失败可能只是网络抖动）。测完自动切回你原来的节点。
每个节点只测一次、结论长期有效——检测会真实动用你的 Google 账号，频繁全量重测容易触发风控； 「全选未测」每个地区至多抽 2 个没测过的节点（多轮自然轮换覆盖），香港/澳门等受限地区默认跳过（仍可手动勾选强测）。
